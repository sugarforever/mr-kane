# Mr. Kane Web MVP Implementation Plan

**Goal:** 用 SvelteKit 和 Pi SDK 实现写作、朗读记录和复习的本地 Web 原型。
**Architecture:** 服务端按请求运行受限 Pi 会话；浏览器保存档案、任务、版本、反馈和录音。无账户、无云同步。
**Tech Stack:** SvelteKit、Svelte 5、TypeScript、Pi SDK、localStorage、IndexedDB、MediaRecorder。

## Scope
- 爱尔兰语、西班牙语；分别保存语言、水平、年级、兴趣、词汇语法目标。
- 任务由技能约束；日常、科学主题及用户提供的新闻、考题材料。无实时新闻检索。
- 写作反馈不打分，保存原文证据、提示、解释、参考改法；独立复习状态。
- 口语仅生成稿件、录音、回放、保存、删除，不做语音识别或评价。
- 无密钥时明确使用固定示例，不伪装 AI 生成或批改。
- 本机开发，不部署公开服务；密钥只在服务端。

## Tasks
- [x] 建立 SvelteKit 工程和领域契约；先验证无效输入、反馈引用和历史保存边界。
- [x] 接入 Pi SDK、受限技能和结构化输出校验；无模型时提供标注的示例。
- [x] 构建今日练习、写作、朗读、复习和学习档案页面；实现本地历史和录音保存。
- [x] 运行单元测试、类型检查、生产构建、HTTP 和浏览器交互验证。

## Review focus
语言切换不能串档；模型失败不能伪装成功；反馈必须引用实际文本；麦克风拒绝与不支持必须可恢复；保存失败不能显示成功；录音替换与删除应释放资源。

## Scope update
The entire product UI and coaching explanations use English. Irish and Spanish are used for learning content. Real microphone capture and authenticated model calls remain device/provider verification items; they are not claimed as tested.
