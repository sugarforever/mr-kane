# IrMO Round 2 Implementation Plan

**Goal:** Add discoverable Irish Mathematical Olympiad final / Round 2 study alongside AoPS, with grounded question retrieval and prerequisite connections.

**Architecture:** Keep AoPS retrieval intact. Add a separate uncompressed competition library, a validated catalog, bounded search/read/image tools, and a browse panel that works without an AI connection. The existing per-conversation learner record and durable chat serve both resources.

**Tech Stack:** Svelte 5 / SvelteKit, TypeScript, Zod, Vitest, Markdown/KaTeX, local PNG assets.

**Spec:** User delegation in this chat, 2026-11-19.

- Use `codex/irmo-round-2` in this checkout; do not merge.
